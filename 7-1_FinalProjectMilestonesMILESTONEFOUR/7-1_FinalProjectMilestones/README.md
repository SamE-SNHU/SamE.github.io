# Databases Artifact

Artifact: CS 330 Computer Graphics and Visualization Final Project  

This artifact demonstrates my ability to integrate a database into a software application. The original project focused on interactive three dimensional visualization, and for my enhancement I added a feature that allows data to be saved and reloaded using a SQLite database. I selected this artifact because it shows how database integration can make software more practical and user friendly by providing data persistence.

To enhance the project, I created a small relational database that stores information about objects, lighting, and camera settings. I wrote functions that insert, update, and retrieve this data as the user saves or reloads a scene. I also tested the database connection to make sure it was stable and that no data was lost. These changes added new functionality and made the program more complete.

This enhancement aligns with the database program outcome by demonstrating my understanding of schema design, data queries, and persistent storage. I also practiced secure and organized data handling so that only valid information is stored. Adding database features gave me hands on experience combining front end and back end components to create a reliable and interactive program.

Through this project, I learned how database design improves both functionality and user experience. Adding persistent data transformed a visualization tool into a program that remembers user progress and settings. This enhancement showed me the value of integrating data management into any kind of application design and strengthened my ability to create well rounded software solutions.
