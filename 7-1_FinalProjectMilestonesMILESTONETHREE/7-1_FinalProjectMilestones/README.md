# Algorithms and Data Structures Artifact

Artifact: CS 330 Computer Graphics and Visualization Final Project  

This artifact represents my ability to use efficient algorithms and data structures to create reliable and optimized programs. The original project generated and rendered three dimensional shapes using mathematical calculations and arrays. It required processing large amounts of data related to vertices, colors, and transformations in real time. I chose this project because it highlights how algorithms directly affect performance and accuracy in computer graphics.

During the enhancement phase, I focused on improving the logic and efficiency of the rendering process. I optimized loops to reduce unnecessary calculations, reorganized arrays for faster access, and refined  formulas for smoother results. I also improved how the program handled timing and updates, which made motion and lighting more consistent. These adjustments increased both performance and visual quality.

This enhancement shows my ability to analyze code and identify areas where efficiency can be improved. I practiced applying computational thinking to reorganize logic and data handling. I also gained insight into how small changes in algorithms can produce major improvements in software performance. These skills reflect the program outcome for algorithms and data structures and demonstrate practical problem solving ability.

Working on this artifact strengthened my critical thinking and debugging skills. I learned to approach complex problems by breaking them into smaller parts and testing each piece carefully. These are valuable abilities for any programmer and show that I can write code that is not only functional but also optimized for speed and accuracy.
