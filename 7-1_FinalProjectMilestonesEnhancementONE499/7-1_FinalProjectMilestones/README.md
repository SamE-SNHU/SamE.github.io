# Software Design and Engineering Artifact

Artifact: CS 330 Computer Graphics and Visualization Final Project  

This artifact was chosen to represent my ability to design and build organized software that follows strong programming practices. The original project was created in my CS 330 course, where I developed a three dimensional scene rendered through OpenGL. It displayed coded objects, lighting, and camera movement within an interactive environment. I selected this project because it challenged me to think through program structure, code organization, and performance while managing multiple source files.

For the capstone enhancement, I focused on improving structure and readability within the code. I organized the project into clear sections, added detailed comments, and used consistent naming to make the code easier to follow. I also reduced redundancy by combining repeated functions and verified that the program compiled cleanly on different systems. These improvements made the software more stable and easier to maintain.

Through this enhancement, I demonstrated my ability to apply software design and engineering principles. I practiced modular programming, version control with GitHub, and documentation that meets professional standards. I also gained experience with the full development process, including design, testing, and refinement. Each update strengthened the reliability and long term quality of the application.

This project helped me understand how thoughtful design leads to dependable results. Clean code improves collaboration and reduces the risk of future errors. Enhancing this artifact increased my confidence in writing organized, maintainable software and how to improve efficiency and teamwork in real world environments.
